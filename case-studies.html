Projects across AI, automation, and data-rich platforms.

A selection of production systems I've designed and built end-to-end — spanning AI-powered recruitment, privacy-first AI products, identity verification, and commerce operations.

AI Recruitment Platform Talent & Hiring

Crayon.jobs

An all-in-one recruitment platform with a service-oriented backend, an API gateway, and dedicated document-processing services. Built AI-powered CV parsing, job-spec parsing, recruiter/candidate conversational workflows, semantic candidate-job matching, and realtime AI interviews.

  • CV ingestion pipeline: SES → Lambda → S3 → SQS → worker → AI parsing → PostgreSQL
  • Deterministic + semantic matching using embeddings in PostgreSQL with pgvector
  • Realtime AI interviews via OpenAI Realtime, WebRTC, and AWS MediaConvert
  • Python/FastAPI document extraction microservice with AI fallback
Node.js Python / FastAPI PostgreSQL + pgvector AWS OpenAI
Privacy-First AI Product Wellbeing & Reflection

The Bridge

A privacy-first AI reflection platform built end-to-end from concept to production — system design, infrastructure-as-code, API implementation, data model, AI layer, and privacy architecture.

  • Pure serverless AWS: ~40 single-purpose Lambdas, 13 DynamoDB tables, EventBridge
  • Realtime streamed AI conversations via a Lambda Function URL + Anthropic Claude
  • Privacy-first identity: KMS-encrypted email ciphertext + HMAC-SHA256 hashing
  • Aggregate-only insights engine analyzing anonymous transcripts, no individual profiling
AWS Lambda DynamoDB Anthropic Claude KMS SAM / CloudFormation

Document Verification System

  • Deployed and operated the production system on AWS EC2
